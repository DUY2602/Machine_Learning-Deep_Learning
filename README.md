# Machine Learning & Deep Learning Projects

A collection of Machine Learning and Deep Learning projects, ranging from cyber security (Malicious URL Detection) to Computer Vision (Handwritten Digit Recognition).

## 🚀 Projects Overview

### 1. Malicious URL Detection

This project uses Machine Learning to classify URLs into four categories: **Benign, Defacement, Phishing, and Malware**.

* **Algorithms:** Random Forest, XGBoost, LightGBM.
* **Best Performance:** Random Forest (~96.6% accuracy).
* **Key Features:** Feature extraction from URLs (IP presence, URL length, TLD, suspicious words, etc.).

### 2. Handwritten Digit Recognition

An interactive application that recognizes digits written by the user on a digital board.

* **Technology:** Convolutional Neural Network (CNN), Keras, TensorFlow, Pygame.
* **Dataset:** MNIST.
* **GUI:** Built with Pygame for real-time drawing and prediction.
